# MITRE ATT&CK Enterprise Tactics Reference

| Tactic | ID | Description | Common Techniques |
|--------|-----|-------------|------------------|
| Reconnaissance | TA0043 | Gathering target info | Phishing for info, scanning |
| Resource Development | TA0042 | Building attack infra | Acquire infrastructure, develop exploits |
| Initial Access | TA0001 | Gaining entry | Phishing, exploit public apps, supply chain |
| Execution | TA0002 | Running malicious code | PowerShell, scripting, WMI |
| Persistence | TA0003 | Maintaining access | Registry keys, scheduled tasks, implants |
| Privilege Escalation | TA0004 | Gaining higher perms | Token manipulation, exploit vulns |
| Defense Evasion | TA0005 | Avoiding detection | Obfuscation, masquerading, rootkits |
| Credential Access | TA0006 | Stealing creds | Keylogging, credential dumping |
| Discovery | TA0007 | Mapping environment | Network scanning, account enumeration |
| Lateral Movement | TA0008 | Moving through network | RDP, SMB, Pass-the-Hash |
| Collection | TA0009 | Gathering data | Screen capture, clipboard data |
| Exfiltration | TA0010 | Stealing data | C2 channels, cloud storage, DNS tunneling |
| Impact | TA0040 | Disruption | Ransomware, data destruction, defacement |
